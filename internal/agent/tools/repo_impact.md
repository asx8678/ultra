Rank the likely blast radius and review order of proposed or existing repository changes.

Seed with repository-relative files, symbols, current uncommitted Git changes, a Git base revision, or any combination. With no explicit seed, the current uncommitted work is used. The result combines bounded, recency-weighted Git co-change history with imports, calls, tests, inheritance, routes, and cross-language literal joins, then returns causal relationships plus suggested read windows. Use exact reads and project tests to verify the ranked candidates.
